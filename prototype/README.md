# Interactive prototype

`calispot-standalone.html` is a local, standalone UI prototype. Open it directly
in a modern browser; no server, build step, or installation is required. Use the
flow selector beside the phone mockup to navigate the concept screens.

The prototype explores outdoor spot discovery and training activity. It is an
earlier visual iteration than the later token reference in `../design-system/`;
the two are presented as related design explorations, not a fully reconciled UI.

This is illustrative front-end content only. It has no backend, live GPS,
authentication, push delivery, or production service integrations.
